# Классная работа 7 — первые алгоритмы в Go

Материалы рассчитаны на первое знакомство с алгоритмами. Мы не начинаем с формул: сначала называем входные данные и одну простую операцию, затем считаем, сколько раз она выполнится при росте входа. После этого применяем тот же подход к поиску, вставке, удалению и сортировкам.

## Как читать комментарии

В каждом основном файле есть четыре части:

1. Что получает и возвращает функция.
2. Что меняется на каждом шаге.
3. Как посчитать время и дополнительную память.
4. Блок «Как не нужно» с конкретной ошибкой и её последствием.

Английскими оставлены только реальные имена Go (`slice`, `map`, `benchmark`, `Quick Sort`, `left`, `right`) и названия задач. Все объяснения даны по-русски.

## Как читать benchmark

Пример строки:

```text
BenchmarkSearch/binary/n=4096-8    42000000    28.4 ns/op    0 B/op    0 allocs/op
```

- `ns/op` — среднее время одной операции; меньше обычно лучше.
- `B/op` — сколько байтов дополнительной памяти выделено на одну операцию.
- `allocs/op` — сколько выделений памяти сделано на одну операцию.
- Суффикс `-8` описывает окружение запуска, а не сложность алгоритма.
- Цифры зависят от компьютера и фоновой нагрузки. Сравниваем результаты одного запуска и смотрим не только на один размер `n`.

Построение `map` и сортировка данных измеряются отдельно от готового поиска. Иначе можно случайно сравнить разные задачи.

## Режим отладки

Файл `docs/debug-guide.md` содержит одинаковый маршрут для GoLand и VS Code с Delve. Поставьте точку останова в `internal/quicksort/quicksort.go` на строке цикла `for scan := left; scan < right; scan++` и наблюдайте за `values`, `left`, `right`, `scan`, `store`, `pivot` и глубиной рекурсии.
