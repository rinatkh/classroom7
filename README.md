# Классная работа 7 — первые алгоритмы в Go

Материалы рассчитаны на первое знакомство с алгоритмами. Мы не начинаем с формул: сначала называем входные данные и одну простую операцию, затем считаем, сколько раз она выполнится при росте входа. После этого применяем тот же подход к поиску, вставке, удалению и сортировкам.

## Маршрут урока

| № | Раздел | Код | Что разбираем |
|---|---|---|---|
| 01 | Сложность | `internal/complexity`, `cmd/01_complexity` | размер входа `n`, число шагов, время и дополнительная память, `O(1)`, `O(log n)`, `O(n)`, `O(n log n)`, `O(n²)` |
| 02 | Поиск в срезе | `internal/search`, `cmd/02_search` | линейный и бинарный поиск, обязательная сортировка входа, позиция вставки |
| 03 | Поиск в map | `internal/maps`, `cmd/03_maps` | индекс и частоты, ожидаемое быстрое чтение, цена построения и память |
| 04 | Вставка и удаление | `internal/insertdelete`, `cmd/04_insert_delete` | сдвиги в срезе, удаление без сохранения порядка, операции с map |
| 05 | Простые сортировки | `internal/simplesort`, `cmd/05_simple_sorts` | пузырьковая, выбором и вставками; сравнения и перестановки |
| 06 | Quick Sort | `internal/quicksort`, `cmd/06_quicksort` | опорное значение, разбиение, рекурсия, средний и худший случаи |

| 08 | Разбор LeetCode | `internal/leetcode`, `cmd/08_leetcode` | адаптированная задача 704 Binary Search: условие → примеры → решение → тесты → сложность |

## Код и контракты

`internal/` содержит готовые алгоритмы, собственные тесты и общий набор входов
в `internal/testutil`. Комментарии фиксируют контракт, границы и инварианты;
подробные объяснения и типичные ошибки вынесены в [docs/algorithms.md](docs/algorithms.md).
Trace сохраняет снимки отдельно от обычного запуска и не входит в benchmark.

## Как читать benchmark

Показатели `ns/op`, `B/op`, `allocs/op` описывают измеряемое тело. `B/op` — allocation, а не полный удерживаемый объём памяти. Числа зависят от CPU, Go и входа: см. [методику](docs/benchmark-guide.md) и [реальные результаты](docs/benchmarks/README.md). На слайдах нет выдуманных или перенесённых из неизвестного окружения значений.

```bash
make bench-search
make bench-sort
make bench-structures
make bench-memory
make bench-all
make trace-mergesort
```

Общий генератор: `internal/dataset.GenerateRandomSlice(n)` с seed 7. Подготовка данных, готовый поиск и серия запросов имеют отдельные группы. Чистая сортировка и copy+sort разделены. Для квадратичных алгоритмов и последнего pivot установлен предел n=512.

## Режим отладки

Файл `docs/debug-guide.md` содержит одинаковый маршрут для GoLand и VS Code с Delve. Поставьте точку останова в `internal/quicksort/quicksort.go` на строке цикла `for scan := left; scan < right; scan++` и наблюдайте за `values`, `left`, `right`, `scan`, `store`, `pivot` и глубиной рекурсии.
