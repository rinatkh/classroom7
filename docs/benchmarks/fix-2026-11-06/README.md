# Повторный замер после исправления classroom7

Команда: `make bench-all BENCHTIME=20ms BENCHCOUNT=3 BENCHCPU=1`.
Go 1.22.12, linux/amd64, AMD EPYC 9V74 80-Core Processor.

Все четыре группы завершились PASS: 326 подзадач, по 3 измерения, 978 строк.
Алгоритмы и методика benchmark сохранены; убраны ошибочные homework-imports
из classroom tests. Рендеринг презентации и параллельные тесты во время замера
не выполнялись. Частота CPU и нагрузка других пользователей контейнера
не контролируются; 20ms — короткий обзорный замер.

- [raw.txt](raw.txt) — реальный вывод команд, без строк оболочки make с локальным путём и лишних пробелов в конце строк.
- [summary.csv](summary.csv) — медианы ns/op, B/op и allocs/op.
- [environment.txt](environment.txt) — версия Go, платформа и параметры.

Именно этот повторный запуск использован на слайдах 23, 57 и 60 исправленной
презентации. Исторический замер по 30ms в родительском каталоге сохранён.
Медианы двух разных прогонов не объединяются.

Для более устойчивого сравнения: `make bench-all BENCHTIME=100ms BENCHCOUNT=5`.
Полная [методика](../../benchmark-guide.md) описывает таймеры, прогрев, данные,
ограничения n и различия контрактов slice / map.
