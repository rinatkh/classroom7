# Пошаговая отладка Quick Sort

Режим отладки позволяет остановить программу на выбранной строке и увидеть текущее состояние переменных. Это не «просмотр всей физической памяти компьютера»: IDE показывает значения, доступные в текущем месте программы, и стек вызовов функций.

## Подготовка

Откройте `cmd/07_benchmark_debug/main.go`. Программа сортирует маленький срез `[7, 2, 9, 3, 5]`, чтобы все состояния помещались на экране.

Точки останова:

1. `internal/quicksort/quicksort.go`: строка, где выбирается `pivot`.
2. Та же функция: цикл `for scan := left; scan < right; scan++`.
3. Строка, где опорное значение ставится на окончательную позицию.

Следите за переменными:

| Имя | Что означает |
|---|---|
| `values` | текущий срез; после перестановки значения меняют места |
| `left`, `right` | границы обрабатываемой части среза |
| `pivot` | опорное значение текущего разбиения |
| `scan` | индекс, который сейчас проверяем |
| `store` | место для следующего значения меньше `pivot` |
| `depth` | глубина рекурсивного вызова |

## GoLand

1. Нажмите слева от номера строки, чтобы поставить красную точку.
2. Запустите `cmd/07_benchmark_debug` через **Debug**.
3. Используйте **Step Over**, чтобы выполнить текущую строку без входа в функцию.
4. Используйте **Step Into**, чтобы войти в `partition` или рекурсивный вызов.
5. В панели **Variables** раскройте `values`; в **Frames** сравните текущий и родительский вызовы.

## VS Code + Delve

1. Установите официальное расширение Go; оно предложит установить отладчик Delve.
2. Откройте `cmd/07_benchmark_debug/main.go` и поставьте точки останова.
3. Выберите **Run and Debug → Launch package**.
4. Используйте **Step Over (F10)** и **Step Into (F11)**.
5. Смотрите панели **Variables**, **Watch** и **Call Stack**.

## Что проговорить на каждом шаге

1. Какая часть среза сейчас активна?
2. Какое значение выбрано опорным?
3. Что сравнивается с опорным значением?
4. Произошла ли перестановка и почему?
5. Какой участок будет обрабатываться следующим?

## Как не нужно

- Не запускайте первый раз Quick Sort на тысяче элементов: состояния невозможно проследить глазами.
- Не меняйте переменные в панели отладчика во время объяснения: тогда таблица шагов и реальное выполнение разойдутся.
- Не делайте вывод о скорости по тому, как быстро вы нажимаете Step Over. Отладчик замедляет программу; скорость измеряет benchmark без точек останова.
